When DataBrain tools are missing

Use these checks before changing settings. They still work when DataBrain has not connected to the chat.

  1. Start a new chat. Extensions become available in conversations after installation.
  2. Check the connection. In Claude Desktop, open the + menu below the chat box, choose Connectors, and look for DataBrain.
  3. Check the installation. Open Settings → Extensions and confirm DataBrain appears there. If it appears installed but its tools are missing, restart Claude Desktop and open another new chat.
  4. If it still does not connect, check its local logs. Open Claude Desktop’s Developer settings and inspect the DataBrain connection status and logs. If Claude says the extension file is corrupted, download a fresh copy and install that file again.

Do not select a wider folder or change permissions to fix a connection problem. For Claude’s current install and troubleshooting steps, see Claude Desktop extension help.
