Set up DataBrain from Terminal

This technical route uses the same index and search engine as the Claude Desktop extension. It requires a local repository checkout and command-line tools.

Technical route. Use the Claude Desktop guide for the conversational setup. If you do not already use Terminal, stop here. Do not use this route to configure the app.

1. Open the product checkout

In Terminal, change to the DataBrain repository. Do not use a prototype checkout or a private brain as the product repository.

cd /path/to/data-brain

2. Choose source folders and install

Replace the sample roots in bin/canon.sh with one quoted path for each folder you want searched. Use existing document folders; do not include the Desktop/DataBrain destination or sensitive folders.

CANON=(
  "$HOME/Documents"
  "$HOME/Downloads/Projects"
)

Then run the installer.

./install.sh

3. Review categories and verify

Follow the taxonomy steps in INSTALL.md in the product checkout. Labels are proposals until you confirm them. Then verify setup and test one known and one absent query.

bash verify-install.sh
bash bin/fts.sh "a known topic"
bash bin/abstain-check.sh "a topic that should be absent"

Refresh later

Refresh the shared index after adding files to approved folders.

bash bin/refresh.sh manual

Save a searchable raw capture

Choose an existing folder already listed in CANON and supply 2–12 lowercase search keywords. The new note is created without replacing files and is added to the index.

printf 'Note text' | bash bin/capture.sh 'Idea' 'project,decision' '/approved/folder'

Keep originals safe

  • DataBrain reads approved roots and writes derived data under its generated index folder.
  • Original documents stay in place.
  • Never include credential or sensitive folders in the source list.
