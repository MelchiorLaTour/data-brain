DataBrain · Claude Desktop · Mac

Your files stay where they are. Claude searches the folders you choose.

01 · DOWNLOAD

Get the DataBrain extension

Download databrain.mcpb to Downloads. Check that the file name ends in .mcpb.

02 · INSTALL

Install it in Claude Desktop

Open Claude Desktop. In the menu bar at the top of your Mac screen, choose Claude → Settings, then open:

Settings → Extensions → Advanced settings → Extension Developer → Install Extension…

Select databrain.mcpb in Downloads and follow the prompts.

Before the setup chat, open DataBrain in Settings → Extensions. Set DataBrain folder location to Desktop; after you approve setup, DataBrain creates its own folder there. Under Folders DataBrain may use, select only document folders you want searched, such as Documents/Work. Do not select Desktop itself or a folder containing DataBrain.

If DataBrain already exists there: it will be left untouched. Choose a different parent in extension settings where a new DataBrain folder can be created.

Then start a new chat Set up my DataBrain.

DataBrain builds a local search index. You choose the folders, review suggested categories, and ask Claude questions about those files. Claude reports files it cannot read; unsupported files are left out of search.

Choose what DataBrain can use

  • Your folder selections grant access; Claude starts reading files only after you confirm setup in chat.
  • Review Claude’s suggested categories before they are applied.
  • After changing source selections, restart Claude. Ask Claude to add the selected folders to keep existing access, or replace the selection to remove access to omitted folders.
  • Ask Claude to audit the install. It checks the running package and saved folder setup. This v0.1.0 prerelease has a known limitation: its GitHub release check looks for a stable release and cannot match this prerelease. A repaired version-matched check is prepared for a follow-up package. It cannot verify the original download file, inspect Desktop’s hidden install record, or prove a restart/fresh chat; GitHub checks may be blocked offline.
  • Ask before saving a capture, note, or synthesis.

Your originals are left alone

  • Search indexes and extracts are created locally.
  • Original documents are not moved or edited.
  • Paths and excerpts you ask Claude to read enter your Claude conversation.
  • New notes are created only after you ask and choose an approved folder.

If the tools are missing: open Settings → Extensions and check DataBrain’s connection status and logs. Restart Claude Desktop, then open a new chat. Claude’s extension help.
