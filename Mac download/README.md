# DataBrain downloads (Mac)

Open the folder for the app you use:

- **[Claude app](Claude%20app)** (available)
- **[ChatGPT app](ChatGPT%20app)** (pre-release)

For the ChatGPT app: Your files stay on your Mac. DataBrain has no cloud server and stores nothing of yours. On ChatGPT, only the query and the snippets needed to answer it are sent to OpenAI's model.

We recommend turning off "Improve the model for everyone" (ChatGPT → Settings… → Data controls). Consumer ChatGPT plans train on chats by default, and the passages DataBrain returns to answer you become part of your chat. DataBrain does not change this setting itself.
