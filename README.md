# DataBrain

DataBrain lets an AI search and read your own notes and files on your computer, without moving or changing them.

Pick your version:

- **[Terminal version (recommended)](Terminal%20version%20%28recommended%29)**: for Claude Code users, on macOS or Windows.
- **[Claude app](Claude%20app)**: for the Claude desktop app (macOS now, Windows later).
- **[ChatGPT app (Mac)](ChatGPT%20app%20%28Mac%29)**: for the ChatGPT desktop app on a Mac. Pre-release.

For the ChatGPT app: Your files stay on your Mac. DataBrain has no cloud server and stores nothing of yours. On ChatGPT, only the query and the snippets needed to answer it are sent to OpenAI's model.
